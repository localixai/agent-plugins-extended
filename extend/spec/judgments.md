# Judgments

Where the Claude Code documentation is silent, or the core and Claude Code disagree, and this
specification decides (E4, U3). A judgment is normative once a chapter states it, but it never
counts toward the conformance report: compatibility is measured only against the documentation.

Each chapter keeps its own judgments in a table at its end, numbered `J<chapter>.<n>`, and the
text that applies one names it ("Judgment J7.3"). Each row says what it decides and the evidence it
rests on. Evidence marked *oracle* is a black-box run of Claude Code's own tools on an input of
ours, with the release named; *reference* is the reading of the reference implementation, checked
against the docs.
